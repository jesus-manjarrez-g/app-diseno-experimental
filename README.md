# App de Diseño Experimental 🌱

App multipágina desarrollada en Python y Streamlit para el análisis de diseños estadísticos en el ámbito agrícola. Creada para la asignatura de Diseño Experimental de Ingeniería Agrícola (Universidad de Sucre).

## Módulos de la App
*   **DCA (Diseño Completamente al Azar):** Disponible ✅
*   **DBCA (Bloques al Azar):** En construcción 🚧
*   **DCL (Cuadrado Latino):** En construcción 🚧
*   **DPD (Parcelas Divididas):** En construcción 🚧
*   **Factoriales:** En construcción 🚧
*   **RSM (Superficie de Respuesta):** En construcción 🚧

## Estructura del Proyecto
*   `app.py`: Portada principal y menú de navegación.
*   `pages/`: Scripts de cada módulo de diseño.
*   `utils/`: Funciones matemáticas y de diagnóstico reutilizables.
*   `data/`: Archivos CSV de ejemplo y variantes de datos.
*   `verificacion/`: Scripts en R para validación cruzada de resultados.

## Cómo ejecutar la app
1. Instalar dependencias en la terminal: `pip install -r requirements.txt`
2. Ejecutar la app localmente o en Codespaces: `streamlit run app.py`
